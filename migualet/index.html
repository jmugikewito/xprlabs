Política de Privacidad

Aplicación: MiGualet
Desarrollador: XPRESSATEC LABS
Última actualización: 18 de Agosto, 2026

Nuestra Promesa de Privacidad: MiGualet es una bóveda financiera y gestor de credenciales construido bajo la premisa de "Offline-First" (Primero Sin Conexión). Nosotros NO recolectamos, transmitimos, ni almacenamos tus datos financieros, tarjetas o contraseñas en ningún servidor externo. Todo vive exclusivamente en tu dispositivo bajo un fuerte cifrado militar (AES-GCM-256).

1. Recopilación y Uso de Datos Locales

Todos los datos introducidos en la aplicación (números de tarjeta, fechas de expiración, CVV, contraseñas, nombres de bancos) son cifrados localmente y almacenados en la base de datos interna de tu dispositivo. El desarrollador no tiene acceso a esta información.

2. Uso de Permisos del Dispositivo

MiGualet requiere ciertos permisos para funcionar correctamente, los cuales se utilizan estrictamente para las siguientes finalidades locales:

  • Cámara (CAMERA): Se utiliza exclusivamente de forma local para capturar imágenes de tarjetas o documentos y vincularlos a tus registros. Ninguna imagen es enviada a la nube.
  • Almacenamiento (READ/WRITE_EXTERNAL_STORAGE): Requerido únicamente cuando el usuario decide voluntariamente generar o restaurar una copia de seguridad (Backup) cifrada de sus datos.
  • Biometría / Huella Digital: Se utiliza para validar tu identidad al abrir la aplicación utilizando el sistema nativo de tu dispositivo. MiGualet no recopila ni almacena tu huella digital.
  • Notificaciones (POST_NOTIFICATIONS): Se utiliza para recordatorios de fechas de pago configurados localmente por el usuario.

3. Servicios de Terceros

Aunque MiGualet no transmite tus datos financieros, la aplicación integra servicios de terceros para funcionalidades operativas específicas:

  • Google Play Billing: Utilizado para procesar la compra de suscripciones (Planes PRO y PREMIUM). La información de pago y facturación es manejada directamente por Google, sujeta a sus propias políticas de privacidad. Nosotros no procesamos pagos directamente.
  • Google AdMob y UMP SDK: En la versión gratuita de la aplicación, utilizamos Google AdMob para mostrar anuncios. Google puede utilizar identificadores de publicidad (como el ID de publicidad de Android) e información del dispositivo para mostrar anuncios personalizados. Hemos integrado la plataforma UMP para solicitar tu consentimiento explícito (GDPR) sobre el uso de cookies y rastreadores publicitarios si te encuentras en regiones aplicables.

4. Seguridad y Copias de Respaldo

Dado que MiGualet no utiliza servidores en la nube, la responsabilidad de mantener copias de seguridad recae sobre el usuario. Recomendamos utilizar la función de "Exportar Copia de Seguridad" (la cual genera un archivo altamente cifrado) y guardarla en un lugar seguro. Si pierdes el dispositivo y no tienes un backup, los datos serán irrecuperables por diseño.

5. Cambios en esta Política

Podemos actualizar esta Política de Privacidad ocasionalmente para reflejar cambios en nuestras prácticas o servicios. Te notificaremos sobre cambios significativos publicando la nueva política en esta página y, de ser necesario, mediante un aviso dentro de la aplicación.
